# 🍃 HEAVEN - "Trà Ngon Biết Nói"

> Website chính thức của thương hiệu trà đặc sản vùng miền & chuỗi nhượng quyền thương mại cao cấp **HEAVEN**.

---

## 📌 Giới Thiệu Dự Án

Website được xây dựng theo phong cách sang trọng, cổ điển giao thoa mộc mạc và hiện đại (Zen & Wood), tối ưu hóa trải nghiệm người dùng và chuyển đổi đối tác hợp tác nhượng quyền.

### 🌟 Tính năng nổi bật:
* **Header thông minh (Sticky & Transparent):** Tự động đổi màu nền khi cuộn trang, nút CTA Nhượng quyền khối vàng nổi bật.
* **Hero Slider (Swiper.js):** Trình chiếu không gian kiến trúc 3D thực tế (K-Town Ocean Park 2, sân vườn hồ cá Koi).
* **Menu Danh Mục Đa Dạng:** Bộ lọc tab không cần tải lại trang (*Trà Đặc Sản, Cà Phê Mộc & Cold Brew, Kem Bơ & Đá Xay, Bánh Ngọt & Tráng Miệng*).
* **Trang Nhượng Quyền Toàn Diện:** Bảng phân tích tài chính gói trung ương & vùng ven, quy trình triển khai 10 bước chuẩn hóa và dự toán chi phí đầu tư.
* **Form Đăng Ký Chuyên Nghiệp:** Tích hợp kiểm tra dữ liệu và phản hồi tương tác mượt mà.
* **Responsive 100%:** Hiển thị sắc nét trên Mobile, Tablet và Desktop.

## 📂 Cấu Trúc Thư Mục

```text
├── index.html        # Trang chủ
├── about.html        # Trang giới thiệu hành trình & giá trị cốt lõi
├── menu.html         # Trang thực đơn đặc sắc (30+ món)
├── franchise.html    # Trang tư vấn & chính sách nhượng quyền
├── contact.html      # Trang hệ thống 6 chi nhánh & liên hệ
├── style.css         # Hệ thống Design System & Stylesheet
├── script.js         # JavaScript điều hướng, slider, filter tab & form
├── assets/           # Hình ảnh đồ uống, không gian kiến trúc 3D thực tế
├── .gitignore        # Cấu hình bỏ qua các file nén và tạm
└── README.md         # Tài liệu hướng dẫn dự án
```

## 🚀 Hướng Dẫn Chạy Website Cục Bộ

1. Mở thư mục dự án bằng Terminal / PowerShell hoặc VS Code.
2. Khởi chạy HTTP Server:
   ```bash
   # Dùng Python
   python -m http.server 8080
   ```
3. Truy cập trình duyệt: `http://localhost:8080`
